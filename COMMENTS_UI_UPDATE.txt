ADMIN PANEL - COMPLAINT MANAGEMENT

==============================================================================
API ENDPOINTS USED
==============================================================================

GET /api/complaints/:id/comments
- Retrieves all comments for a complaint
- Response: { comments: [...], success: boolean }

POST /api/complaints/:id/comments
- Adds new comment to complaint
- Request: { text: string }
- Response: { comment: {...}, success: boolean }
